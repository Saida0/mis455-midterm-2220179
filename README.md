# Leaf & Brew Tea House

MIS 455 Midterm (Practical) project by **Sumaya Binte Saida (2220179)**.

A three-page website for an online tea shop that sells hand-picked loose-leaf teas.

## Pages
- `index.html` – Home page (uses `display: flex` for the hero, features and about sections)
- `products.html` – Products page (uses `display: grid` for the product cards)
- `contact.html` – Contact Us page with a message form

## Features
- Header, footer and navigation bar with hover effect on every page
- At least 2 paragraphs and 2 images on every page
- Buttons with `onclick` JavaScript: Get Welcome Offer, Show Me a Tea Tip, Add to Cart, Clear Cart, Send Message
- Responsive layout for tablets and phones

## Files
- `style.css` – all styles
- `script.js` – all JavaScript functions
- `images/` – logo and illustrations
